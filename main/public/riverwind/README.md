# RiverWind Bank — Standalone Redesign

This is a standalone static frontend redesign inspired by the supplied RiverWind Bank homepage screenshot and the bank's publicly available product/page structure.

## Run
Open `index.html` directly, or serve the folder:
- Python: `python -m http.server 8080`
- Then visit `http://localhost:8080`

## Included
- Modern responsive design system
- New global header/navigation and mobile navigation
- Redesigned homepage
- Personal banking, checking, savings, CDs/IRAs, cards, loans
- Mobile and online banking
- Calculators
- Breezy Bundle
- Kasasa Cash, Cash Back, Saver and comparison
- Business banking, deposits, loans and cards
- Services, locations, contact
- History and team
- Blog index + reusable article template
- Search demo
- Legal/security/privacy/FDIC page shells

## Important production notes
- Online banking login is a UI demo only and intentionally does not submit credentials.
- Contact/application buttons are frontend placeholders until connected to approved bank workflows.
- Legal pages are structural shells and should be replaced with RiverWind's approved legal/compliance copy.
- Current rates/APYs should be verified before publishing.
- Replace remote Google Fonts with self-hosted fonts if required by the bank's deployment/security policy.
